# NEXORA — Demo web empresarial 2026

Demo navegable para presentar una **página web principal conectada con catálogos especializados**.

## Incluye
- Portal principal de NEXORA (presentación del negocio, categorías, destacados y contacto).
- 4 catálogos independientes: Perfumería, Moda, Tecnología y Accesorios.
- Perfumería dividida en Dama, Caballero y Unisex, con filtros adicionales por marca.
- Filtros por subcategoría, público, marca, búsqueda y orden de precios.
- 27 productos de ejemplo con fichas detalladas y representaciones gráficas vectoriales.
- Favoritos guardados localmente en el navegador.
- Flujo demostrativo de consulta: permite copiar un mensaje, sin enviar pedidos reales.
- Diseño responsive para móvil, tableta y escritorio.
- Navegación compatible con links directos a cada catálogo y subcategoría.

## Abrir o presentar
1. Abra `index.html` en un navegador. No requiere instalación ni servidor.
2. Para publicar una demo pública, despliegue toda la carpeta en Vercel (proyecto estático) o servicio similar.
3. Navegue por Perfumería → Dama / Caballero / Unisex y filtre por marca.

## Importante
La marca NEXORA, los productos, descripciones, precios e ilustraciones se muestran con fines de **demostración**. Esta entrega **no** se conecta a una base de datos, inventario real, pasarela de pago o cuenta de WhatsApp. Para producción se requiere confirmar la identidad comercial y datos del cliente, catálogo, fotos reales y flujo de pedidos deseado.

## Estructura
- `index.html`: estructura web.
- `styles.css`: apariencia y diseño responsive.
- `app.js`: catálogo, navegación, filtros, favoritos y consulta simulada.
- `vercel.json`: compatibilidad con despliegue estático.
